# 剪易 · 拼图

独立纯浏览器子项目。直接双击 `index.html`，或使用现有静态服务访问 `/collage/`，无需安装依赖、无需上传图片。遵循主项目 LICENSE。

1. 添加或拖入最多 9 张图片，单张不超过 30 MB。
2. 选择网格、主图、横向、纵向或自定义网格布局，调整比例、留白、圆角和背景色。
3. 默认“移动图片”模式，拖动时图片跟随指针、原位置淡化；拖到另一张图片上松开即可互换，裁切设置随图片保留。切换“调整裁切”后拖动裁切；方向键在两种模式下分别互换和微调。选择“完整显示”保留全图。
4. 用图片列表的上下箭头排序、叉号移除。选择导出长边，下载 PNG。

支持浏览器可解码的 JPEG、PNG、WebP 等普通图片；GIF 作为静态图片，SVG 不支持。导入时长边超过 3000 像素的图片会缩小以控制内存。透明背景图片可导入，成品使用所选实色背景。

支持手动保存浏览器本地草稿；刷新或关闭前请点击“保存草稿”。从顶部“草稿”列表选择打开，也可命名、覆盖保存、另存新草稿和删除。草稿包含图片、布局、裁切与文字，与视频编辑器草稿独立；相同浏览器和站点地址下可复用，清理网站数据会删除，不会跨设备同步。大尺寸导出受设备内存限制，手机建议选择 1200 px。未接入主编辑器时间线或 CLI。

- `index.html` / `style.css`：独立工作台与移动端布局。
- `app.js`：图片解码、素材管理、Canvas 预览与导出。
- `workspace.js`：文字绘制、放大预览、30 步撤销重做与 IndexedDB 草稿。
- `layout.js`：归一化布局算法，供预览和导出共用。
- `layout.test.cjs`：布局边界、覆盖与重叠验证。

开发检查：`node --check collage/app.js`、`node --test collage/layout.test.cjs`（在项目根目录运行）。

自定义网格支持 1–9 行，每行可独立设置 1–9 列，例如三行分别设置 1、2、3 列。行高等分，每行内部按列数等分宽度，最多仍导入 9 张图片。容量不足自动增加最后一行列数，保留指定行数且不隐藏图片。空白格预览显示虚线，导出为背景色；当前互换只针对已有图片，不支持移入空格、合并单元格或单独调整格子宽高。

点击“放大预览”进入铺满浏览器窗口的编辑区，保留拖动与撤销工具；按 Esc 或“退出放大”返回。文字支持添加多段独立内容，每段支持换行（最多 200 字、10 行）、字号、颜色和位置，选择“移动文字”后拖动或用方向键微调，通过文字列表或预览点击选中，独立修改或删除；旧版单段文字草稿可继续打开。文字同步进入 PNG 导出。

撤销与重做最多保留当前会话 30 步，支持 Cmd/Ctrl+Z、Cmd/Ctrl+Shift+Z 和 Ctrl+Y；文本输入框保留自身快捷键。打开草稿后重新开始历史记录。

布局区提供“1:2:2:2”快捷预设：四行，依次为 1、2、2、2 列，共七格。应用后可继续修改每行列数；图片超过七张时，沿用自定义网格规则增加末行列数。

“单图”预设适用于一张图片：切换到单格并将留白、圆角设为 0，图片铺满画布，沿用当前画布比例。多张素材时会提示先保留一张，不会自动删除图片。之后继续添加多张图片则沿用自定义网格自动扩容规则。

顶部可切换“拼图 / 表情包”。两个工作台在本次页面会话内分别保留内容、撤销历史与草稿关联；刷新前仍须各自保存。表情包默认原图比例、单图无边框，提供顶部大字与底部配文，重新导入会替换底图并保留文字。草稿列表显示作品类型，打开时自动切换；旧草稿归为拼图。当前表情包仅支持静态 PNG 导出，动态 GIF 尚未实现。
